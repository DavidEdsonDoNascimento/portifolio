Static WOFF subsets (latin) of Space Grotesk and JetBrains Mono, used only to render
the Open Graph image (`src/lib/og-image.tsx`) and the resume PDFs. The site itself loads
the same families through `next/font`. Both fonts are licensed under the SIL Open Font
